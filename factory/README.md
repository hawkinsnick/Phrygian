# Corpus Factory

This directory is a reusable scaffold for building source-attributed ancient-language and epigraphic corpora.

## Factory stages

1. **Discover** — register candidate sources and rights status.
2. **Acquire** — capture only material whose access and redistribution terms permit the chosen workflow.
3. **Normalize conservatively** — preserve source readings and editorial uncertainty; never overwrite originals.
4. **Model** — select a corpus-specific record profile rather than forcing all projects into one schema.
5. **Validate** — run structural, provenance, replay, export, and negative tests.
6. **Release** — publish only after integrity checks pass; independent scholarly review remains a separate gate.
7. **Interop** — expose the shared epistemic safeguards through interoperability contract 1.1.

The factory standardizes provenance and validation, not linguistic conclusions.

# Rights and redistribution

This repository's own code and original metadata may be licensed separately from third-party source-derived material.

No blanket permission is inferred from public web access. Before redistributing source text, images, facsimiles, or substantial transcriptions, record the applicable source terms and scope. When redistribution rights are unclear, store only provenance, identifiers, hashes, locators, and derived metadata necessary for reproducibility.

TITUS and underlying editions remain attributed as sources; their terms control their material.

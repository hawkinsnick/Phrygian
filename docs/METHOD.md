# Method

The project separates source capture, transcription, normalization, interpretation, and review.

For Phrygian, uncertainty marks, missing signs, restorations, directionality, line/face boundaries, and editorial interventions must be retained as source evidence. Normalized or Greek-script renderings are secondary representations and must never overwrite source readings.

A checksum proves byte integrity of a captured source, not epigraphic correctness. A digital source entry is not automatically an independent physical witness. Alternate editions and duplicate digital presentations must be linked rather than counted as new evidence.

Old- and Neo-Phrygian remain explicit period partitions. Analyses must declare which partition is used.
